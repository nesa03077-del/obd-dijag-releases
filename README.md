# OBD Dijag: izdanja

Android aplikacija za dijagnostiku auta preko Bluetooth OBD2 adaptera (ELM327).

**Preuzimanje:** otvori [poslednje izdanje](https://github.com/nesa03077-del/obd-dijag-releases/releases/latest)
i preuzmi `.apk` fajl na telefon.

Instalirana aplikacija sama proverava nove verzije: **Podešavanja → Ažuriranje aplikacije → Proveri ažuriranja**.
